## 📖 About Vedaverse

**Vedaverse** is a web-based knowledge project created to bring together selected spiritual, devotional, and philosophical works in an accessible digital experience.

The project presents individual works through dedicated pages and combines them with navigation, search, daily content, and a simple web interface for exploration.

> **Ancient knowledge, presented through a modern digital experience.**

---

## ✨ Features

- 📜 **Sacred verses and devotional works**
- 🕉️ **Vedic and philosophical content**
- 🔱 **Shiva-related works and prayers**
- 🪷 **Bhaja Govindam and other classical works**
- 📚 **Shankaracharya works**
- 📅 **Daily mantra / verse experience**
- 🔎 **Search functionality**
- 🌐 **Dedicated pages for individual works**
- 📱 **Web-focused, accessible presentation**

## 🚀 Getting Started

### Run locally

Clone the repository:

```bash
git clone https://github.com/leomani2714/Vedaverse.git
cd Vedaverse
```

Then open `index.html` in a modern web browser.

For the best experience, you can also serve the project through a simple local web server.
