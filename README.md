# Vedaverse

Vedaverse is a static collection of Vedic scriptures, devotional chants, mantras, and Tamil works, presented as a responsive website.

## Run locally

Requirements: Node.js/npm and Python 3.

From the project directory, run:

```bash
npm start
```

Open [http://localhost:8000](http://localhost:8000). No `npm install` is needed; the npm scripts start Python's built-in static file server.

To use a different port, for example when port 8000 is already occupied:

```bash
PORT=8001 npm start
```

You can also run the development server directly with `npm run dev`.
